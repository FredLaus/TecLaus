# TecLaus
TecLaus é o jogo educativo que transforma matemática em um RPG incrível! 🎮 Desafie-se em 1000 níveis (do A1 ao Nível Mundial), domine o modo real de "Somar os Caixas" e encontre erros contábeis. Mantenha sua ofensiva diária para ganhar moedas LENES, mude o cenário com as estações do ano, compre skins e dispute as Olimpíadas OLT e OAEP no 1v1 !🚀
